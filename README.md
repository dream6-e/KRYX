# KRYX

纯 Rust、无外部依赖的 Luau 混淆器基础框架。

目前只包含命令行参数处理、输入文件读取和输出文件名计算，**尚未实现语法解析、压缩或任何混淆步骤**。因此不会生成或覆盖 `.K.lua` 文件；读取成功后会提示功能尚未实现并返回非零退出码。

```sh
cargo run -- test.lua
cargo test --offline
```

将来实现混淆后，`test.lua` 的默认输出路径为同目录的 `test.K.lua`。以 `-` 开头的输入文件名可用 `cargo run -- -- -file.lua` 指定。输入按原始字节读取，当前不进行语法或编码校验。
